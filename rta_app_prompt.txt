あなたはJavaプログラマーです。以下の要件で、最小構成のRTA管理WebアプリをSpring Boot + Maven + H2（メモリ）で作成するための設計・実装方針と雛形コードを提示してください。

【前提】
- 参照UI: rs3_rta_tool.html に実装されているRTA管理UIのうち、次のデータを保存できること
  - 各キャラクターの数値（剣レベル、JP など）
- 画面は rs3_rta_tool.html の主要構成・入力項目を再現する（見た目は近似で可）
- 目的は「再現 + データの保管」
- ユーザー管理・ログインは不要

【使用技術】
- 言語: Java
- フレームワーク: Spring Boot
- ビルド: Maven
- DB: H2（インメモリ）

【要求】
1. CRUD開発に必要な依存関係（pom.xml）
2. 推奨ディレクトリ構成
3. クラス名やメソッド名の命名規則
4. 主要エンティティ設計（例: CharacterStatus など）
   - 必須フィールド: キャラ名、剣レベル、JP
   - 更新日時/作成日時があるとなお良い
5. 画面構成
   - rs3_rta_tool.html の入力項目をベースに、登録・更新・一覧・削除ができる画面
6. コントローラ/サービス/リポジトリの雛形コード
7. 起動方法

【出力形式】
- 設計の説明 + 雛形コード（主要部分）
- 省略してよいが、最低限動く構成
- 文章は日本語
